# 📖 Overview

InsightIQ is an AI-powered Business Intelligence and Decision Support Platform that transforms raw business data into meaningful, actionable insights.

Unlike traditional dashboards that only visualize data, InsightIQ intelligently analyzes datasets, generates executive summaries, forecasts business performance, identifies risks, recommends strategic actions, and helps organizations make data-driven decisions.

The platform combines Artificial Intelligence, Business Intelligence, Analytics, Forecasting, and Data Visualization into a single integrated solution.

---

# 🎯 Why InsightIQ?

Modern organizations generate massive amounts of data but often struggle to extract meaningful insights.

InsightIQ bridges this gap by combining AI-driven analytics with business intelligence to help organizations:

- Make smarter business decisions
- Understand performance trends
- Detect business risks early
- Forecast future growth
- Generate executive-level reports
- Discover actionable recommendations

# 🚀 Getting Started

## Clone the Repository

```bash
git clone https://github.com/RudranshGupta08/InsightIQ.git

cd InsightIQ
```

---

# 📦 Backend Installation

```bash
cd backend

npm install

npm start
```

---

# 💻 Frontend Installation

```bash
cd frontend

npm install

npm run dev
```

# 🔐 Environment Variables

## Backend (.env)

```env
PORT=5000

MONGO_URI=your_mongodb_connection_string

JWT_SECRET=your_jwt_secret
```
